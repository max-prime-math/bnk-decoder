Creating or Editing an Algorithm

There are no formatting options for constants, conditions, and user-defined functions, since only variables can be
inserted into questions, narratives, or matching groups. If you have a value that is a constant or condition and you
want to display it, you will need to create it as a variable.

In order to make your algorithms easy to understand or debug, you may want to include comments in your algorithm
definitions. To add a comment, type the pound sign (#) followed by your comment in the Definition field.

 1. Create a new question, narrative, or matching group.
 2. Click Edit from the menu bar and select Algorithm Definitions.

    The Edit Algorithm Definitions window opens.

 3. Click New to create a variable, constant, condition, or user-defined function.

    Once an algorithm is created as a particular type: variable, constant, condition, or user-defined function, you
    will be unable to change the type.

 4. To add algorithms to an existing item, click Edit from the menu bar and select Algorithm Definitions, select the
    algorithm name and definition, and click Edit.
