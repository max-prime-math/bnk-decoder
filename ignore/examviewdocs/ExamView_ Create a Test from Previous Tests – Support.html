    As of June 30, 2024, ExamView will officially reach its end of life.

    Please be advised that after ExamView’s end-of-life date of June 30th, 2024, we will no longer be providing updates, security patches, or technical support for any version of ExamView. Our obligations to maintain or support ExamView will cease as of this date. Continued use of ExamView post end-of-life may expose you to increased security vulnerabilities, compatibility issues, and potentially reduced functionality.     You can export previously created tests as question banks and then use those question banks to build a cumulative test in ExamView Test Generator.

    1. In ExamView Test Generator, open one of your previous tests.
    2. Click File > Export > ExamView Question Bank..., as shown in the figure below.

      You will be creating an ExamView question bank from the test.

    3. In the Export Test window, navigate to where you want to save the newly created question bank.

      By default, ExamView will save the newly created question bank in ExamView > Tests. To efficiently find the banks, consider creating a new folder in the ExamView > Tests path to save your new bank in, as shown in the figure below.

    4. Enter a name for the question bank and click Save, as shown in the figure above.

      Repeat the above steps for each test that you want to convert to a question bank.

    5. Click Help > Welcome Screen to return to the What do you want to do? window.
    6. Using your preferred way to create a new test, create a new test using the question banks you just created in above steps.
    7. Save the cumulative test.
